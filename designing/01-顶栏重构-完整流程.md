## 概述

把原来的 `DisplayStudioBreathHeader.vue`（及其英文/繁中副本）重构为一个 Astro 组件
`src/components/studio/Header.astro`，零 Vue 依赖，SSR 渲染，纯 CSS 动画。

```

       ├─ src/css/reset.css
```

## 分步实现

### 第 1 步：把横条做出来，保证文件结构正确

**目标**：`Header.astro` 输出一个基础的 `<header>`，并且 `studio.astro` 正确引用它，页面能显示这个横条。

**需要做的事**：

1. **编辑 `src/components/studio/Header.astro`**：把现在的骨架改成只输出一个 `<header>` 标签，删除 `<html>`、`<head>`、`<body>`。

   骨架内容：
   ```astro
   ---
   ---

   <header>
     <div class="top-bar">
       <!-- 内容暂时为空，后面一步步加 -->
     </div>
   </header>
   ```

2. **编辑 `src/pages/studio.astro`**：在 `<StudioLayout>` 的 slot 里引入 `Header.astro`。

   ```astro
   ---
   import StudioLayout from "@/layouts/StudioLayout.astro";
   import Header from "@/components/studio/Header.astro";
   ---
   <StudioLayout
       title="河南大学网站工作室 | HENU Web Studio"
       description="河南大学网站工作室成立于2001年..."
   >
       <Header />
   </StudioLayout>
   ```

3. **验证**：`pnpm dev` 打开页面，能看到顶栏出现（目前是空的）。

**关键点**：`Header.astro` 是 Astro 组件（`.astro`），不是 Vue 组件（`.vue`）。
Astro 组件天然 SSR，不需要 `client:load`，不会有框架 JS 开销。

### 第 2 步：让横条能接受深色模式，加入切换深色模式的按钮

**目标**：顶栏能跟随 `html.dark` 切换深浅色样式，并且有一个按钮让用户切换。

#### 2.1 深色模式的基础

`StudioLayout.astro` 已经根据 cookie 给 `<html>` 加上了 class：

```astro
const isDark = Astro.cookies.get('theme')?.value === 'dark'
---
<html class={isDark ? 'dark' : ''}>
```

全局 CSS（`theme.css` + `base.css`）已经定义了 CSS 变量和基础元素样式。
`Header.astro` 不需要自己感知主题——它用 CSS 响应 `html.dark` 即可。

#### 2.2 顶栏的深色样式

在 `Header.astro` 的 `<style>` 里写：

```css
.top-bar {
  position: fixed;
  top: 0; left: 0; width: 100%;
  min-height: 3rem;
  padding: 0.3rem 1rem;
  z-index: 1000;
  display: flex;
  align-items: center;
  transition: background-color 0.3s, color 0.3s;
  border-bottom: 1px solid rgba(20, 20, 20, 0.2);
}

/* 亮色 */
.top-bar {
  background: #f5f5f5;
  color: #333;
}

/* 深色 — 通过 :global(.dark) 监听 html 的 class */
:global(.dark) .top-bar {
  background: #2c2c2c;
  color: #f0f0f0;
}
```

**为什么要用 `:global(.dark)` 而不是 `.dark`？**
因为 Astro 的 `<style>` 默认是 scoped 的，它会为选择器加上自动生成的属性。
`.dark` 在 `<html>` 上，不在当前组件内，所以要用 `:global(.dark)` 穿透。

#### 2.3 主题切换按钮

按钮本身是 HTML：

```astro
<button id="theme-toggle" class="theme-toggle">
  <span id="toggle-icon">🌙</span>
  <span id="toggle-label">暗色</span>
</button>
```

按钮样式（在 `<style>` 里）：

```css
.theme-toggle {
  padding: 0.4rem 0.8rem;
  font-size: 0.9rem;
  background: transparent;
  border: 1px solid;
  border-radius: 6px;
  cursor: pointer;
  color: inherit;
  transition: background-color 0.3s;
}
.theme-toggle:hover {
  background-color: rgba(128, 128, 128, 0.15);
}
```

切换逻辑（在 `<script>` 里）：

```html
<script>
  const btn = document.getElementById('theme-toggle')
  if (!btn) return
  const icon = document.getElementById('toggle-icon')
  const label = document.getElementById('toggle-label')

  // 初始化时把按钮文字和服务端渲染的主题对齐
  function syncUI() {
    const isDark = document.documentElement.classList.contains('dark')
    icon.textContent = isDark ? '☀️' : '🌙'
    label.textContent = isDark ? '亮色' : '暗色'
  }

  btn.addEventListener('click', () => {
    const isDark = document.documentElement.classList.toggle('dark')
    document.cookie = 'theme=' + (isDark ? 'dark' : 'light') + '; path=/; max-age=31536000'
    syncUI()
  })

  syncUI()
</script>
```

**关键点**：所有切换逻辑在 Astro 的 `<script>` 里完成，纯原生 JS，0 KB 框架。
服务端渲染输出的初始按钮文字取决于 cookie，但 Astro 组件里直接读取 cookie 需要
在 frontmatter 里拿到 cookie 值。不过用 CSS 技巧可以绕过（见第 5 步 logo 处理）。

### 第 3 步：横条加入呼吸动画

**目标**：顶栏像呼吸一样慢慢伸缩。

参考旧项目的 `DisplayStudioBreathBarHeader.vue`（最简洁的版本）：

```css
@keyframes breathe {
  0%, 100% { transform: scaleY(1); }
  50%      { transform: scaleY(1.03); }
}

.top-bar {
  animation: breathe 4.75s ease-in-out infinite;
  transform-origin: top center;
}
```

**为什么用 `scaleY` 而不是 `scale`？**
`scaleY(1.03)` 只让顶栏纵向拉长，里面的内容（文字、图片）也会被拉伸，
视觉上就是"膨胀/收缩"的效果。宽度不变，不影响两侧布局。
`transform-origin: top center` 保证从顶部向下膨胀，不向上顶出内容。

**为什么 CSS 在 Astro 组件里是 scoped 的？**
Astro 的 `<style>` 会自动添加 scoped 属性，不影响其它组件。
`.top-bar` 这个类名只在当前 `Header.astro` 里生效。

### 第 5 步：处理 Logo 颜色切换逻辑

**目标**：深色模式显示白色 logo，亮色模式显示黑色 logo。

**方案**：两个 `<img>` 标签 + CSS 显隐，**不需要 JS，不需要 `logoMap.ts`，不需要 `computed`**。

```css
/* 默认（亮色）：显示黑色 logo */
.logo-dark { display: none; }

/* 深色：显示白色 logo，隐藏黑色 logo */
:global(.dark) .logo-light { display: none; }
:global(.dark) .logo-dark { display: block; }
```

**为什么这是最好的方案？**
1. SSR 时两个 `<img>` 都渲染到 HTML，浏览器直接显示，不需要 JS 介入
2. 切换主题时，CSS 变量 `.dark` 变化，logo 立刻切换，没有 JS 延迟
3. 不需要 `useThemeObserver`、`logoMap.ts`、`computed` 这些 Vue 工具

对比旧项目做法：
```
旧（Vue）：            useThemeObserver → computed → logoSrc（JS 控制）
新（Astro + CSS）：    两个 img + :global(.dark) 显隐（纯 CSS）
```

### 第 6 步：处理移动端媒体查询

**目标**：移动端（<= 48rem）隐藏标题文字，调整布局间距。

参考旧项目的移动端布局（`DisplayStudioBreathHeader.vue` 的 mobile 部分）：

```css
@media (max-width: 48rem) {
  .title-text { display: none; }
}
```

完整的顶栏布局（flex）：

```css
.top-bar {
  display: flex;
  align-items: center;
  justify-content: space-between;
}
```

**为什么不用 `v-if="!isMobile"` / `v-else`？**
旧项目用 `useMediaQuery` + Vue 的 `v-if` 在桌面端和移动端渲染两套完全不同的
HTML 结构。Astro 的方案是一套 HTML + CSS 媒体查询控制显隐，避免了：

1. JS 依赖（不需要 `useMediaQuery.ts`）
2. 两套模板的维护成本
3. SSR 与客户端渲染不一致的问题

**移动端和桌面的 layout 差异**：

| 元素 | 桌面 | 移动 |
|------|------|------|
| logo | 显示 | 显示 |
| 标题文字 | 显示 | 隐藏 |
| 论坛/考试链接 | 显示 | 隐藏 |
| 雨伞菜单 | 隐藏 | 显示 |
| 主题切换按钮 | 右侧 | 右侧 |

桌面端布局示意：
```
[logo + 标题文字]  ......  [前往论坛] [考试系统] [🌙 暗色]
```

移动端布局示意：
```
[Logo]  ......  [☰] [🌙]
```

### 第 7 步：处理移动端雨伞菜单

**目标**：移动端显示一个雨伞菜单按钮，点击后弹出下拉菜单。

旧项目的 `UmbrellaMenu.vue` 是一个 183 行的 Vue 组件，功能包括：
- 雨伞图标按钮（切主题时换图标）
- 下拉弹窗（论坛、考试系统、摇一摇开关、漂浮触发）
- 摇一摇检测（`useShakeDetector.ts`）
- 事件总线通信（`eventBus.ts`）

**有一个问号待确认**：

这个组件在旧项目里深度依赖 Vue（`ref`、`computed`、`onMounted`、`eventBus`、
`useShakeDetector`）。在新架构下，可以有两种处理方式：

| 方案 | 做法 | 优缺点 |
|------|------|--------|
| **A: Vue island** | 保留 UmbrellaMenu.vue，`studio.astro` 里 `<UmbrellaMenu client:load />` | 功能保持完整，但多了 Vue runtime 和 JS 体积 |
| **B: 重写为原生 JS** | 把必要的功能（弹窗展开/收起、导航跳转）用 Astro `<script>` 实现，去掉摇一摇/事件总线 | 更轻量，但需要重新实现弹窗逻辑 |

**建议**：先问清楚用户对雨伞菜单的定位——是保持完整功能（摇一摇、漂浮等），还是简化成基本的导航弹窗。这个决定影响第 7 步的实现方式。

## 总结：新旧对比

| 方面 | 旧（Vue） | 新（Astro） |
|------|-----------|-------------|
| 框架 | Vue 3 component | Astro `.astro` 组件 |
| 渲染 | 客户端渲染（`client:load`） | 服务端渲染（SSR） |
| JS 体积 | ~50 KB Vue runtime + 组件代码 | 0 KB（theme toggle 仅 ~15 行原生 JS） |
| 主题感知 | `useThemeObserver`（MutationObserver） | `:global(.dark)` CSS 选择器 |
| Logo 切换 | `computed` + `logoMap` | 两个 `<img>` + CSS 显隐 |
| 呼吸动画 | `useBreathingMode.ts` + `breathe-stretch` 等 class | 纯 CSS `@keyframes breathe` |
| 响应式 | `useMediaQuery` + `v-if` / `v-else` | CSS `@media` 控制显隐 |
| 深色切换 | `PlasticThemeToggleIsland.vue` + 语言变体 | 内联 `<button>` + `<script>` |
| 语言变体 | 3 套独立文件（zh/en/zhtw） | 后续统一成 props/data |
