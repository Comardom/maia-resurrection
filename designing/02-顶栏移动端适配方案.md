## 背景

顶栏目前只做了桌面布局。移动端需要：**布局重构（logo 居中）**、触控优化、弹窗适配。呼吸动画保留。

## 技术选型

| 手段 | 用途 |
|------|------|
| `@media (max-width: 48rem)` | 布局切换（断点沿用旧项目 768px） |
| `@media (pointer: coarse)` | 触控优化（按钮尺寸） |
| `@media (hover: hover)` | hover 效果降级（避免触摸"粘住"） |

不使用 UA 检测，理由见 `01-顶栏重构-完整流程.md` 及 `ACCESSIBILITY.md`。

## 一、HTML 结构调整（核心改动）

logo 居中需要把顶栏从"两栏"改成"三组"。左右组各只保留一个按钮，logo+标题独立成 `center-group`：

```html
<div class="top-bar">
    <div class="left-group">
        <button id="theme-toggle" class="theme-toggle" aria-label="切换主题">
            <img src="/luna-black.svg" class="icon icon-luna-black" alt="" />
            <img src="/solar-white.svg" class="icon icon-solar-white" alt="" />
        </button>
    </div>
    <div class="center-group">
        <a href="/" class="logo-wrapper">
            <img src="/plastic-black-trans-wswd.svg" class="logo logo-light" alt="" />
            <img src="/plastic-white-trans-wswd.svg" class="logo logo-dark" alt="" />
        </a>
        <span class="title-text">河南大学网站工作室</span>
    </div>
    <div class="right-group">
        <button id="app-menu-toggle" class="app-menu-toggle" aria-label="打开应用中心"
            aria-expanded="false" aria-controls="app-menu">
            <img src="/more-black.svg" class="icon icon-more-black" alt="" />
            <img src="/more-white.svg" class="icon icon-more-white" alt="" />
        </button>
    </div>
</div>
```

> 弹窗（`#app-menu`、`#app-menu-backdrop`）结构不变，本方案不涉及。

## 二、桌面端：CSS `order` 还原现有布局

桌面视觉保持 `[logo 标题] …… [🌙] [▦]`，靠 flex `order` + 自动外边距实现，**不用改 HTML**：

```css
.top-bar {
    display: flex;
    align-items: center;
    gap: 1rem;
    /* 其余已有属性（position/min-block-size/padding 等）不动 */
}
.center-group { order: -1; }                              /* logo 排最左 */
.left-group   { order: 2; margin-inline-start: auto; }   /* 主题按钮推到右段 */
.right-group  { order: 3; }                              /* 应用菜单最右 */
```

效果：`[logo 标题] 自动空隙 [🌙] [▦]`，与现在一致。

## 三、移动端：grid 三栏完美居中

```css
@media (max-width: 48rem) {
    .top-bar {
        display: grid;
        grid-template-columns: 1fr auto 1fr;   /* 中间 auto 保证 logo 绝对居中 */
        gap: 0;
    }
    .left-group   { grid-column: 1; justify-self: start;  order: 0; margin-inline-start: 0; }
    .center-group { grid-column: 2; justify-self: center; order: 0; }
    .right-group  { grid-column: 3; justify-self: end;    order: 0; }
    .title-text { display: none; }             /* 标题文字去掉 */
}
```

效果：`[🌙] …… [logo] …… [▦]`，logo 精确居中。

## 四、触控优化

### 4.1 按钮尺寸达标（仅触屏设备）

桌面保持 `2.5rem`；触屏设备放大到 44px 达标 WCAG 触控目标：

```css
@media (pointer: coarse) {
    .theme-toggle,
    .app-menu-toggle {
        inline-size: 2.75rem;
        block-size: 2.75rem;
    }
}
```

### 4.2 hover 效果降级

触摸设备无真实 hover，`:hover` 会"粘住"。限定在有 hover 能力的设备：

```css
@media (hover: hover) {
    .theme-toggle:hover,
    .app-menu-toggle:hover,
    .app-menu-close:hover {
        background-color: rgba(128, 128, 128, 0.15);
    }
}
```

## 五、弹窗适配

```css
@media (max-width: 48rem) {
    .app-menu {
        block-size: 22dvb;   /* 桌面 25dvb → 移动端 22dvb */
    }
    .app-menu-close {
        inline-size: 4rem;           /* 桌面 6.5rem → 移动端 4rem，触控目标加宽 */
        margin-inline-end: 1.375rem; /* 圆框圆心与开启按钮同纵线 */
    }
    .app-menu-tiles {
        padding: 1rem;                                        /* 3rem → 1rem */
        grid-template-columns: repeat(auto-fill, minmax(4.5rem, 1fr));  /* 375px 屏可排 3-4 列 */
    }
}
```

### 关闭按钮圆心对齐推导

移动端：
- 顶栏 `padding-inline: 2rem`，开启按钮（触控下 2.75rem 圆）圆心距屏幕右缘 = `2rem + 1.375rem = 3.375rem`
- 关闭竖条 `4rem` 宽，圆框在竖条内居中，圆心距竖条右缘 = `2rem`
- 竖条右缘需往左缩 `3.375 − 2 = 1.375rem` → `margin-inline-end: 1.375rem`

> 该值依赖顶栏 padding（2rem）和开启按钮直径（2.75rem），改任一项需重算。

弹窗高度：桌面基础 `25dvb`（用户设定），移动端覆盖为 `22dvb`。

## 七、修复：200% 缩放下关闭态磁贴穿帮

> 状态：已修复并写入代码
> 现象：未展开菜单时，能看到蓝色磁贴（`#007ACC`）有一边露出。

### 根因

关闭态隐藏菜单完全依赖 transform 的数学精确性：

```css
.app-menu {
    transform: translateY(-100%);   /* 只靠这个把面板移出视口 */
}
```

`translateY(-100%)` 的百分比相对**元素自身 border-box 高度**计算，而高度来自
`block-size: 30dvb`。在 200% 缩放等场景下，动态视口单位（`dvb`）的解析与
transform 百分比的分辨率基准可能不一致，导致实际渲染高度比 translate 用的高度
多出一点点 → 面板底部（磁贴区）露出一条边。`transition: transform 0.3s` 让这个
偏差在关闭态也稳定可见。

磁贴有 `padding: 3rem`，所以露出的不是面板白底，而是靠里的蓝色磁贴边。

### 修复方案：可见度隐藏（visibility）

不依赖 transform 的精确性，给关闭态加硬隐藏：

```css
.app-menu {
    transform: translateY(-100%);
    visibility: hidden;              /* 关闭态彻底不渲染，防缩放穿帮 */
    pointer-events: none;            /* 关闭态防误触 */
    transition: transform 0.3s ease,
                visibility 0s linear 0.3s;   /* 滑出结束后再隐藏 */
    display: flex;
}
.app-menu.open {
    transform: translateY(0);
    visibility: visible;             /* 立即显示，再执行滑动 */
    pointer-events: auto;
    transition: transform 0.3s ease,
                visibility 0s;
}
```

要点：

- **关闭态** `visibility: hidden`：元素完全不参与渲染，无论 transform 差多少像素都不会露出
- **打开**：`.open` 时 `visibility: visible` 立即生效（`visibility 0s`），再执行 0.3s 滑动，视觉不变
- **关闭**：先滑出 0.3s，结束后 `visibility` 才变 hidden（用 `0s linear 0.3s` 延迟）
- `prefers-reduced-motion` 块已把 transition 设为 `none`，visibility 会瞬时切换，不受影响
- 与现有 `.open` class、`inert`、`aria-hidden` 逻辑完全兼容
