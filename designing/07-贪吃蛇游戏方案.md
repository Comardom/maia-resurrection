# 贪吃蛇游戏设计方案（07）

> 目的：为「红色块全屏过渡 → 贪吃蛇游戏」的完整方案存档，供后续手动重写参考。
> 关联：`designing/` 下各方案文档、`src/game/`（当前实现）、`redTransitionScript.ts`（进出过渡）。

## 一、需求概述

1. **演示蛇**（桌面端，红色块未点击时）：一条用「河南大学网站工作室」作身子的贪吃蛇，在红色块内沿 **S 型路径**循环演示「吃字 → 吐字」
2. **正式游戏**（点击红色块，全屏过渡后进入）：经典方块贪吃蛇，像素风、键盘控制、localStorage 最高分、结束界面含重玩/返回
3. **移动端不做**（演示蛇与正式游戏都不做）
4. 音效暂缓（后续可选 Web Audio API）

---

## 二、文件结构

```
src/game/
├── words.ts        # 蛇身文字共享：BODY_WORDS = ['河','南','大','学','网','站','工','作','室']
├── engine.ts       # canvas 工具：fitCanvas / calcGrid / cssVar
├── demoSnake.ts    # 演示蛇：S 型 吃/吐 循环
└── snakeGame.ts    # 正式游戏：方块蛇 + 键盘 + 存档 + 结束/重玩
```

- 全部**纯 TS**，不依赖 Astro/Vue
- 通过 `import()` 动态加载（`snakeGame` 独立 chunk，不拖慢 `/studio` 首屏）
- `redTransitionScript` 只负责进出过渡，游戏模块完全解耦

## 三、通用工具 `engine.ts`

```ts
fitCanvas(canvas)         // 读取 clientWidth/Height × devicePixelRatio(≤2) 适配分辨率，返回 ctx
calcGrid(w, h, cols)      // 固定列数，行数按宽高比；格子取整数，网格整体居中
                          // 返回 { rows, cols, cell, originX, originY }
cssVar(name, fallback)    // 读取 CSS 变量（主题色等）
```

**网格单位说明**：canvas 内部绘图是像素坐标系，不用 rem/svb。网格按视口像素计算（固定 24 列 → 行数自适应 → 格子整数 → 居中），任意屏幕完整显示且像素对齐。

## 四、演示蛇 `demoSnake.ts`

### 4.1 挂载
- `.band-red` 内 `createElement('canvas')`，class `demo-canvas`，`position:absolute;inset:0;pointer-events:none`
- 尺寸跟随红色块：`ResizeObserver` 监听，更新画布 + 网格

### 4.2 网格与路径
- `COLS = 16`，行数按红色块宽高比
- **S 型路径**：逐行蛇形扫描（`y` 偶数行从左到右、奇数行从右到左），生成全网格坐标序列
- 第一排 `(x,0)` 预置 9 个字（左起）

### 4.3 状态机（吃 → 回 → 吐 → 循环）
```
Phase 'eat':
  蛇头沿 S 型路径逐格前进（TICK_MS = 180ms/格）
  蛇头经过第一排且有字 → 吃掉：字从第一排消失，push 进蛇身文字串
  走完整个 S 型 → phase = 'return'

Phase 'return':
  蛇头沿路径倒退回第一排起点（headIdx--）

Phase 'spit':
  蛇头再沿 S 型走一遍
  经过第一排 → 吐回一个字（蛇身 pop，第一排对应格恢复）
  全部吐出 → 回到 'eat'（headIdx=0, headHist=[]）
```

### 4.4 渲染
- 蛇头：色块（`--studio-tile` 蓝）
- 蛇身文字：`fillText` 逐字渲染在蛇头历史位置之后（`headHist[i+1]`），字体 `Huiwei-HKHei`
- 第一排待吃字：淡色（`globalAlpha 0.55`）
- 文字色 `--theme-color`（浅色深字/深色浅字）

### 4.5 生命周期
- `start()` / `stop()`；`prefers-reduced-motion` 时不启动

## 五、正式游戏 `snakeGame.ts`

### 5.1 挂载
- `#game-overlay` 内 `createElement('canvas')`，id `game-canvas`，`position:absolute;inset:0;image-rendering:pixelated`
- **注意**：canvas 是 JS 后 append 的 absolute 元素，会盖住 overlay 里的 `#game-exit` 按钮——按钮需 `z-index:5` 浮到其上

### 5.2 网格
- `COLS = 24`，行数按 `canvas高/宽` 推出，格子取整数居中

### 5.3 玩法
- 蛇：经典方块，初始 3 格，起点居中
- 食物：随机空位红色方块；吃 → 蛇长 1 + 得分 + 加速
- 碰撞：撞墙 / 撞自身 → 游戏结束
- **速度**：`BASE_TICK_MS = 210`（初始），`MIN_TICK_MS = 110`，每吃 10 个减 `10ms`
- 禁止 180° 掉头（`dir.x + d.x === 0 && dir.y + d.y === 0` 时忽略）

### 5.4 控制
- 方向键 / WASD 转向；空格 暂停/继续；`Esc` 返回；结束界面 `R` 重玩
- 结束界面文案：「游戏结束 / 得分 X 最高 Y / 按 R 重玩 · 按 Esc 返回」

### 5.5 存档
- `localStorage` 键 `snakeBest`：最高分，结束更新、进入读取

### 5.6 主题适配
- `isDark()`：`document.documentElement.classList.contains('dark')`
- 画布底色：浅色 `rgba(255,255,255,0.6)` / 深色 `rgba(0,0,0,0.55)`
- 文字/结束遮罩同样跟随主题（浅色深字 + 白遮罩，深色白字 + 黑遮罩）
- overlay 背景 CSS：浅色 `rgba(255,255,255,0.75)`，`:global(.dark)` 下 `rgba(0,0,0,0.6)`

### 5.7 退出按钮
- `setExitVisible(visible)`：`reset()` 时隐藏（`opacity:0; pointer-events:none`），游戏结束时显示

### 5.8 生命周期
- `start(container)`：加载 best、创建 canvas、绑定键盘、启动 rAF、ResizeObserver
- `destroy()`：停 rAF、解绑键盘、disconnect observer、remove canvas

## 六、与 redTransitionScript 集成

```
initRedTransition()（桌面端 only）:
  demo = startDemo(red)                     // 红色块常驻演示蛇
  red click → enterGame()                   // 若 timeline 已存在则忽略

enterGame():
  lockNavigation(true)                       // 锁翻页（pageAnimator）
  document.documentElement.classList.add('game-mode')
  gsap.to('.top-bar', { yPercent: -110 })   // 顶栏向上收起（平滑）
  捕获七块 flex 位置 → 同帧转 absolute（gsap.set）
  rainbow.classList.add('transitioning')    // 抑制 hover 高度/Game Start
  gsap timeline 三幕：
    幕1: 红块向左扩（吃左侧空隙）+ 六块两两重叠 95%（露 5% 左缘）
    幕2: 六块整摞滑出右屏 + 红块 top:0/100%×100% 满屏
    幕3: 红块 opacity→0.2
  onComplete → showOverlay():
    demo.stop()
    import('@/game/snakeGame').then(m => game = m.startSnakeGame(overlay))

exitGame()（overlay 退出按钮 / Esc）:
  overlay 淡出 → timeline.reverse()（原路返回）
  onReverseComplete → finishReverse():
    game.destroy()
    恢复 flex（gsap.set 清 position/left/top/width/height）
    game-start clearProps（交还 CSS hover 控制）
    rainbow.classList.remove('transitioning')
    document.documentElement.classList.remove('game-mode')
    gsap.to('.top-bar', { yPercent: 0, clearProps: 'transform' })  // 顶栏滑回
    lockNavigation(false)
    demo = startDemo(red)                    // 恢复演示蛇
```

**关键经验（踩过的坑）**：
1. **捕获时机**：必须先读 `offsetLeft/offsetTop/offsetWidth/offsetHeight`（flex 布局下），再同帧 `gsap.set position:absolute`。若先加 `.transitioning` class（其 CSS 设 absolute）再读位置，会读到错乱坐标 → 七块消失/错位
2. **顶栏动画**：CSS `animation: breathe-y` 会覆盖 transform 过渡，必须用 gsap 控制位移，`.game-mode` 只停 animation
3. **Game Start 粘滞**：退出后 `game-start` 若用 gsap.set 内联 opacity:0 会永久压制 CSS hover（内联优先级高于样式表），需 `clearProps` 彻底交还 CSS
4. **reduced-motion**：跳过动画直接 `showOverlay` / `finishReverse`

## 七、移动端（≤48rem / 无 hover）

- `isDesktop()`（`matchMedia('(hover: hover)')`）为 false 时不启动演示蛇、不绑红色块点击进游戏
- 移动端红色块保持手风琴交互（展开 short / 跳转箭头），不涉及游戏
